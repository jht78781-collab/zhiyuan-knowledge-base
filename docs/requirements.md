# 第一版需求规格

| 编号 | 功能与验收结果 |
|---|---|
| F01 | 管理员创建账号、设置角色、停用或重置密码。用户可以登录和退出，失效会话无法继续调用接口。 |
| F02 | 管理员创建、编辑和删除知识库并绑定独立 Dify 应用。知识库管理成员可以编辑对应资料和分配成员权限。 |
| F03 | 允许上传含文字的 PDF、DOCX、UTF-8 TXT。页面展示处理状态及失败原因，管理成员可重试可恢复的索引和清理任务。 |
| F04 | MinIO 保存原件，数据库保存对象标识。下载入口校验知识库、文档及用户权限。 |
| F05 | 使用 Dify Knowledge API 上传、查询索引和删除文档。索引完成的文档可供问答。 |
| F06 | 用户在授权知识库内发起问答。资料不足时显示提示，接口失败或来源越界时隐藏原回答并记录失效原因。 |
| F07 | 一个会话属于一位用户和一个知识库。用户可续问、查看或删除自己的历史。撤销权限后，相关历史即时不可访问。 |
| F08 | 展示经验证的来源名称、片段和授权下载。在历史中标记已删除的原件并隐藏其片段。 |
| F09 | 记录成功、失败、单次耗时及 Dify 返回的实际 Token。按日期聚合，并显示缺少总 Token 的调用数。 |
| F10 | Web 工作台支持登录、知识库和文档、智能问答、用户管理及用量统计。 |

## 权限规则

| 身份 | 访问范围 |
|---|---|
| 系统管理员 | 管理系统账号和所有知识库，查看聚合用量，读写本人的会话。 |
| 知识库管理成员 | 管理授权知识库的名称、文档及成员，可以提问和访问本人的历史。 |
| 知识库查看成员 | 查看索引完成的文档、提问、访问本人的历史。 |

第一版以部门外的知识库成员授权为边界。自助注册、部门层级、多租户、OCR、Excel 和旧版 DOC、流式浏览器输出、复杂计费报表在本版范围外。
